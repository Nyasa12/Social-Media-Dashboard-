# Social-Media-Dashboard-

AuraMetrics is a Streamlit-based social media analytics dashboard built in a single Python file (app.py). It helps visualize and analyze Instagram ads and creator performance using interactive charts.

Features
Instagram ads performance analysis
Creator/content insights tracking
Interactive charts and graphs (Plotly)
Clean dashboard UI with Streamlit
Dark mode support
Fast and lightweight single-file app

Tech Stack
Python
Streamlit
Pandas
NumPy
Plotly

Clone the repository:
git clone https://github.com/your-username/aurametrics.git
cd aurametrics

Install dependencies:
pip install streamlit pandas numpy plotly

Run the app:
streamlit run app.py
